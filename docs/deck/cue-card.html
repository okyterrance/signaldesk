3 · How AI was used 1:41 – 2:48

Screen: panel 3 — factor table left, sources + system prompt right

  • Data: 12 RSS feeds (6 crypto, 6 macro) · Binance public API for prices · Fear & Greed index for sentiment. All free, no keys.
  • Ranking: eight factors — how consequential · how recent · outlet quality · how many outlets corroborate · how many hard figures. Weighted, normalised to 0–1.
  • That is an algorithm, not a model. Same input, same ranking, every time — 148 offline tests.
  • The model does exactly one job: it writes up the list the algorithm already chose.
  • Point at the prompt: already ranked · selection is not your job · never invent a number.
  • Kimi K3 → Grok 4.3 fallback. Built with Claude Code.
  • Why split it: if a model picks the stories and picks wrong, you can't find out why. Here a wrong lead story is a wrong factor weight — see it, test it, fix it.

Screen: panel 4 — the two rankings side by side
